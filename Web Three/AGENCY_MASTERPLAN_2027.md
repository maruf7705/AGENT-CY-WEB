## ⚙️ 3. BACKEND & INFRASTRUCTURE (The Engine)

To support this cutting-edge agency and its clients, the architecture must handle heavy AI orchestration, vector databases, and real-time streaming.

### The Stack:
*   **Frontend (The Face):** Next.js 14/15, React Three Fiber (for 3D), Framer Motion (for smooth 60fps animations), TailwindCSS.
*   **Backend (The Brain):** Python FastAPI + Node.js. 
    *   *Why?* Python is king for AI (LangChain, LlamaIndex), Node is great for real-time web sockets.
*   **Workflow Engine (The Nervous System):** n8n (Self-hosted or Cloud). n8n acts as the glue connecting external APIs, scheduling agent runs, and handling webhooks.
*   **LLM Orchestration:** LangChain & LangGraph (for multi-step loop reasoning).
*   **Models:** 
    *   *Cloud:* DeepSeek-Coder (coding), GPT-4o / Claude 3.5 Sonnet (general reasoning).
    *   *Local/Edge:* **Nous Hermes 3** (Llama-based) for uncensored, high-speed, private autonomous tasks inside workflows.
*   **Database:** PostgreSQL (with pgvector for Semantic Search/RAG).

### How Products are Built (N8N + AI to Product)
1. **The Lead Engine (Example Web App):** 
   * Client logs into the Next.js dashboard.
   * Client types a target market.
   * Next.js hits an n8n webhook API.
   * n8n triggers a Python LangChain script.
   * **Agent 1 (Hermes):** Scrapes the web for companies.
   * **Agent 2 (LangChain + GPT):** Analyzes their websites for pain points.
   * n8n compiles the data and pushes it back via WebSocket to the Next.js frontend as a beautifully formatted 3D table.
